# HANTA INC

A Next.js + TypeScript strategy simulation about evolving an original pathogen, balancing spread, cure pressure, random events, and an alien intervention twist.

## Scripts

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Merge safety

If GitHub shows conflicts on the scaffold files (`app/globals.css`, `app/layout.tsx`, `app/page.tsx`, or `tsconfig.json`), use the branch that contains only the latest fix commits on top of the merged scaffold. The current source keeps those files formatted and type-safe so follow-up fixes can merge cleanly without reintroducing the stale one-line scaffold diff.
